**Detected version:** Next.js **15.5.18**. Confirmed two ways: `version:"15.5.18"` in the framework chunk, and `window.next.version === "15.5.18"` (`appDir: true`) in the browser console.
**Latest patched 15.5.x at time of check:** **15.5.28** (10 patch releases ahead).

Source: GitHub Advisory Database, queried 2026-11-01 23:10 IST:
`GET /advisories?ecosystem=npm&affects=next@15.5.18` → 14 advisories.

## React Server Components advisories
The vendored React string is `19.2.0-canary-0bdb9206-20250818`. Next.js ships its own patched copy of `react-server-dom-webpack`. RSC issues such as CVE-2025-55182 (React2Shell) are tracked as Next.js advisories, and none of those match 15.5.18, so they are **already patched** in this version. They are not counted again.

## Conclusion
Upgrading `next` from **15.5.18 → 15.5.28** is a patch-level bump (no breaking changes within 15.5.x). It closes **2 High + 1 Medium advisories that match the observed architecture**, plus the conditional ones. Pair it with automated dependency updates (Dependabot/Renovate) so security patches don't fall 10 releases behind again.

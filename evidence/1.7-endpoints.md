# 1.7 Endpoint inventory

Captured 2026-11-01 23:15–23:20 IST in a normal browser session (no login) from India, plus the headers from 1.4 and the bundle analysis from 1.6.
Logged-in flows (assessment portal) are **not yet captured**. See tracker step 1.7b.

## A. Pages (GET, HTML or RSC)

| Route | Rendering | `Cache-Control` | Edge cache | RSC prefetch time* |
|---|---|---|---|---|
| `/` | SSG | `public, max-age=0, must-revalidate` | HIT | n/a |
| `/services`, `/bitelevate`, `/story`, `/team`, `/impact`, `/products` | SSG | same | HIT | 48–66 ms |
| `/contact` | ISR (`stale-time 300`) | same | HIT | 47 ms |
| `/careers` | **dynamic** | `private, no-cache, no-store, max-age=0, must-revalidate` | MISS | **282 ms** |
| `/case-studies` | **dynamic** (inferred from timing) | n/a | n/a | **253 ms** |
| `/blog`, `/blog/[slug]` | **dynamic** | `private, no-cache, no-store, …` | MISS | **287 ms** |
| `/sitemap.xml` | **dynamic** | `public, max-age=0, must-revalidate` | MISS | n/a |
| unknown path | static 404 page, status 404 | `public, max-age=0, must-revalidate` | HIT | n/a |

\* From the browser's Resource Timing API on the home page. The App Router prefetches every in-viewport `<Link>` with `GET <route>?_rsc=…`. Static routes answer from the edge in ~50 ms; dynamic routes run a serverless render and take ~5× longer.

**Home page load:** 45 requests, 351 KB transferred from `www.cynbit.in`, TTFB 305 ms, DOMContentLoaded 651 ms, load 1 144 ms. That includes **9 background RSC prefetches**, 3 of which invoke dynamic serverless renders on every home-page view.
